# KooComic Next 设计评审决策

2026-10-12，用户确认采用第 3–10 问的推荐方案。本记录补充目标规格，不表示功能已经实现或服务端能力已经验证。

## 卷身份与系列整理

- 没有可信共同卷标识时，不凭同名自动合并文件版本；保留独立记录并标记待确认。
- 系列优先使用可信系列 ID，其次系列名与作者；不确定的归入未分类。
- 第一版提供本地归入系列及拆分系列，后续同步保留整理结果，不修改云端。
- 未下载卷存在多个版本时，优先服务端明确指定的默认版本；没有可信默认则要求选择，不凭上传时间或大小推断最佳版本。选择完成后其余卷继续批量入队。

## 下载与恢复

- 下载期间能浏览、返回、暂停和取消是发布要求；不接受只能停留在下载界面的降级。
- 第一版不要求边下载边阅读；进入阅读器前暂停队列，当前传输须安全结束或中断。
- 重启后等待手动继续；运行中的短暂网络故障按限定次数重试。
- 认证失效或空间不足暂停整个队列；单卷损坏等独立失败记录后继续下一卷。
- 允许保存当前空间无法容纳的待下载清单，实际执行前逐卷检查空间。

## 本地副本与路径

- 账号及仅本地卷边界见 ADR-0003。
- 删除后保留历史路径映射；同卷同版本重新下载时，原路径安全且未被其他文件占用就复用，新版本使用独立路径。
- 阅读位置是否恢复以真机结果为准。

## 沿用原始命名

用户要求新版本沿用现有默认书名来源。当前代码的界面书名来自 KOOBONE 的 `vol_name`；本地文件名使用该字段，经文件名安全化后加扩展名，字段缺失时沿用既有回退规则。当前代码不从下载响应的文件名推导书名，不能据此确认 KOOBONE 返回的名字与 Kmoe 原始下载文件名完全相同。

新版本保留云端原始书名，不用系列解析结果或手动整理结果重写书名，不自动重命名既有本地文件。新文件不再默认统一附加短 ID；只有同名冲突时如何分配独立路径尚待确认，且不得覆盖其他卷或版本的文件。
