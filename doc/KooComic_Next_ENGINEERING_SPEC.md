## 1. 目标与范围

进入 KooComic 后，导航、封面比例、系列文件夹、数量徽标、选中反馈和底部翻页应具有 Bookshelf 的视觉一致性。移除其大型顶部书籍预览区，释放空间给漫画目录；保留 KooComic 的远程发现、下载和本地管理职责。

本规格细化原始 Next SPEC §3、§9 的视觉要求。已确认的账号隔离、卷与文件版本关系、原始书名、虚拟系列目录和显式删除规则继续适用。原始 spec 的功能范围不因视觉对齐扩大。本文待用户评审后，才作为 UI 实施依据；若与此前已确认决策冲突，先暴露冲突并修订。

不复制 Bookshelf 的本地阅读进度、评分、当前在读面板或微模块仪表盘；不注册其远程 Source，不依赖它安装，不修改 Bookshelf 源码。本次不决定下载文件重名后缀，不改变文件名或路径。

原始 Next SPEC §1 的“不直接复制其代码”是此前仅参考外观的方案。本修订将其调整为：允许按第 12 节固定版本、保留许可与署名地复用绘制组件，自带必要源码并隔离设置；不整包引入 Bookshelf 的业务与运行时。原始归档文件保留原文，后续统一规格时按本修订更新这一复用边界。

## 3. 页面骨架

```text
┌─────────────────────────────────────────┐
│ [返回]  系列 | 单卷 | 已下载     [搜索]   │  分类条：约 44dp
├─────────────────────────────────────────┤
│ 当前路径 / 同步状态                      │  按需出现，最多 28dp
│                                         │
│  封面＋文件夹     封面＋文件夹    ...      │
│       ×N              ×N                │
│                                         │  内容区：可用高度优先
│  封面＋文件夹     封面＋文件夹    ...      │
│                                         │
│                                         │
│ [菜单]   [首页][上页]  1/4  [下页][末页] [队列] │  单行页脚：约 40dp
└─────────────────────────────────────────┘
```

图仅表示区域关系，不表示卡片数量、触控目标或最终像素位置。没有单独的顶部 Hero、常驻账号信息横幅、搜索输入框、三按钮搜索/排序/筛选工具栏或第二排底部导航。

## 4. 视觉与布局参数

| 项目 | KooComic 初始值 | 验收约束 |
|---|---|---|
| 页面背景 | 白；夜间模式反转 | 不增加装饰背景或纹理 |
| 分类条 | 44dp；字号变化时允许 40–52dp | 文字和图标垂直居中，触控目标至少 40dp |
| 路径/状态条 | 正常可隐藏；显示时不超过 28dp | 不能用它塞入第二排永久工具栏 |
| 单行页脚 | 40dp；可扩到 48dp 以容纳触控目标 | 翻页、菜单、队列处于同一排 |
| 页面左右边距 | 取 `min(16dp, 屏宽×3%)` | 左右对称，所有网格列和导航共享边界 |
| 列间距 | 12dp 起始值 | 不得挤压触控区域或出现相邻卡片重叠 |
| 卡片圆角 | 沿用上游 `Space.px(4)` 的形状尺度起点 | 不将 4 固定设备像素误当上游实现；按屏幕自然尺度缩放，保持墨水屏边界清晰 |
| 卡片边线 | 约 1 个设备像素 | 真机上可辨认，不形成粗重外围框 |
| 阴影 | 沿用上游约 `Space.px(4)` 的偏移尺度 | 不用模糊阴影；不进入相邻触控区 |
| 普通标签字体 | 沿用 KOReader UI 字体，初始 14dp | 不随视口宽度缩字；字号增大后重新排版 |
| 系列文件夹名称 | 初始 14dp、粗体、最多两行 | 与文件夹底部标签一体，不再附加标题段落 |
| 页码与辅助状态 | 初始 12dp | 不以不可读小字换取更多封面 |
| 字距 | 0 | 保持原始中文字形与字体排版 |

上述值是布局起点。调整时维护一组统一参数，不能针对某个书名或某张截图分别微调。

复用上游 `Space` 的自然屏幕尺度与 DPI 上限算法时，不再在外层重复应用 `Metrics.dp()`。文字/触控尺寸继续按 KOReader 的字号和实际缩放计算，形状/间距使用独立的形状尺度，避免大字号同时放大所有空隙。原来“最终上限 8px”的固定设备像素约束改为小圆角的视觉要求；真机记录最终半径和缩放，不能为满足一个固定像素上限破坏参考比例。

## 5. 导航与返回

**UI-01 · 全屏主体验**：打开后首先显示漫画目录或可用缓存，内容使用完整可用屏幕；没有介绍页。未登录、无可展示的远程缓存时显示登录入口，同时保留独立的设备级本地管理入口，可以查看、打开和显式删除已索引本地文件。不能露出前账号私有远程目录；本地入口不要求先登录，也不因远程目录页不可用而消失。

**UI-02 · 分类条**：默认三个视图为“系列 / 单卷 / 已下载”。选中项黑底白字，其他项白底黑字，采用相邻薄边线的 Bookshelf 风格；右侧为搜索图标。分类条是同一份 Catalog 的投影，不复制数据。

**UI-03 · 导航记忆**：切换分类保留各自页码、排序和查询；进入系列后以短路径条显示系列名称。系统 Back、右滑返回和返回图标均回到上一层并恢复原来的页码。横向翻页手势不得被同时解释为目录返回：右滑返回只在非翻页区域或已约定的边缘区域生效，边界由真机交互验证固定。

**UI-04 · 统一页脚**：左侧菜单图标，中部首页/上一页/页码/下一页/末页，右侧队列图标及有限数量徽标。菜单承载同步、排序、筛选、本地管理、账号和设置。窄屏优先隐藏首页/末页，保留上一页、页码、下一页和两个角入口；不得压小触控目标。第一页/最后一页的无效翻页按钮禁用。多选时同一位置替换为选择操作条。

## 6. 系列卡片

**UI-05 · 默认结构**：默认以一张代表封面为主体，在其底部覆盖具有左上索引耳的文件夹标签；名称写在标签内，右上以 `×N` 标记卷数。索引耳宽取卡片宽度约 40%，耳高跟随实际字体行高。封面底部被标签适度遮挡，不能把整个封面盖成文字块。默认不渲染三张重复封面叠层；可选叠放样式推迟。

**UI-06 · 卷数与状态**：`N` 是不同卷的数量，同卷多个版本不重复计数。数量徽标借鉴 Bookshelf 外观，但不得把 KOOBONE 或 KOReader 的已读数量混入。存在本地副本时显示一个下载图标及本地卷数的小徽标，与总卷数区分，不能用含糊的 `3/19` 同时表达下载、阅读和选中数量。partial 状态显示“已发现 N 卷”而非真实总数；partial 仍不是获准发行的受限版本。

**UI-07 · 名称与封面**：名称使用已确认的系列名称，默认最多两行，超长显示省略号，完整名称在进入系列后的路径/详情中可读。封面优先选择第一卷的有效封面，缺失时用其他可用封面；同一系列在翻页/同步时不因下载顺序随意换封面。默认不在卡片下再重复系列名、作者和进度。

文件夹标签灰阶使用可辨认的灰底与黑字；Colorsoft 可使用接近上游的低饱和纸质标签色作为局部元素，页面和导航仍以黑白为主。使用颜色不能改变文件夹、下载和选中的语义辨认。

## 7. 单卷卡片与网格

**UI-08 · 封面大小优先**：竖屏优先从 3 列尝试，横屏优先从 4 列尝试；允许因屏幕、字号与封面尺寸退到更少列。不得先规定 3×3 再缩小封面。自动布局在满足下列条件的候选中选择可容纳行数最多的方案：

- 普通漫画封面显示宽度至少 120dp，并至少占所在列可用宽度的 85%；特殊宽高比以完整展示为先，不能拉伸。
- 标签、阴影、数量徽标和触控边界全部包含在稳定的卡片尺寸内。
- 一张封面可以在选中、下载状态变化前后保持相同大小。
- 大字号下不能压缩文字；减少行列数或切换列表回退。

120dp 与 85% 是本草案的可读性基准，不是已测量的 Colorsoft 结论。真机评审可调整并记录理由；更多封面数量不能覆盖可读性要求。

**UI-09 · 图片处理**：保持封面原始比例，使用原生图像缓存及目标尺寸解码；图像本身不裁切、不伸长。系列首页允许 UI-05 的文件夹标签覆盖封面底部，这是明确设计的覆盖层，不以裁切图像实现；进入系列的普通单卷及详情须能查看完整封面，单卷状态徽标只占角落的小区域。存在多个封面尺寸时选择足以覆盖实际渲染尺寸的资源，避免反复放大低分辨率缩略图。只有低分辨率资源时保留低清封面并允许占位/列表回退，不把示意图放大效果当作真机验证。

**UI-10 · 单卷标签**：原始 `vol_name` 保持不变，最多两行，可省略显示但详情呈现完整原名。默认不增加固定作者行，作者放详情或可选扩展显示。卷序排序不改书名，不把排序解析结果写回文件名。

**UI-11 · 单卷状态**：未下载状态无需常驻文字占一行；已下载、排队、传输和失败使用小型图标/短徽标，靠形状与文字区分。下载进度只在正在下载的卷上显示。默认不绘制 Bookshelf 的本地阅读进度条或评分，避免虚假状态。

**UI-12 · 间距分配**：同一行封面或文件夹卡片共享底部基线。行与行之间只有统一间距，卡片内不把剩余高度分配到标题和作者之间。剩余页面空间优先按 Bookshelf 的外侧/行间间距思路分配；不足一整行时不能让最后一行被页脚裁切。只有少量系列时保留真实空白，不造卡片填满画面；0 项时页码不出现 `1/0`。

## 8. 进入系列、搜索和多选

**UI-13 · 系列内页**：沿用同一分类条、边距和页脚；路径条显示当前系列，单卷按自然卷序排序。默认不加一整排常驻“下载未下载卷/管理”大按钮；系列操作从菜单进入，多选通过长按卷或菜单“选择”进入。这样把空间留给封面，同时保留操作可达性。

**UI-14 · 搜索与筛选**：搜索图标打开输入界面或覆盖面板，不常驻占高。搜索结果在同样的封面网格展示，并给出查询及结果数；清除搜索后恢复原分类和页码。排序和筛选在菜单中，生效时路径/状态条可显示短摘要；全部结果被过滤掉时提供清除条件入口。

**UI-15 · 单击语义**：普通状态下单击系列进入卷列表，单击单卷进入详情；已下载卷的详情提供打开阅读。不会因单击而立即启动下载或删除，也不会像 Bookshelf 带 Hero 的焦点模式那样只更新一个不可见预览区。

**UI-16 · 多选反馈**：长按单卷进入多选，点击勾选/取消；选中使用黑色描边与勾选符号，禁止仅变色。进入多选不移动卡片或改变页码。跨页保留选择，选择状态按稳定 ID 而非数组位置维护；切换账号清空选择。系列首页长按系列打开系列操作菜单，不默认选择所有卷，避免系列和卷的选择语义混淆。

**UI-17 · 多选页脚**：使用原页脚高度，显示已选卷数及下载、删除本地、取消操作。窄屏保留数量、取消及操作菜单，不挤出第二行。只选未下载卷时删除本地不可执行；混合选择时删除预览只统计有效本地文件。退出多选清除选择并恢复分页控件。

**UI-18 · 详情与确认**：单卷详情沿用 KOReader 原生风格，显示完整书名、作者、版本、本地文件和明确来源的进度信息。批量下载和删除均使用原生确认界面；删除展示实际文件数、大小和失败结果，不让系列卡片的数量代替文件数。所有模拟稿的已下载、进度、空间和队列数据须标为示例，不将书名或目录同步数量推断为本地已下载状态。

## 9. 系统状态与墨水屏

**UI-19 · 缓存与同步**：可用缓存先显示；同步不清空网格，不自动跳回首页。状态条或菜单显示同步时间/失败；未验证完整时不能显示“已同步全部”。云端新增导致排序变化时优先保留当前所见卷的定位，不把选中项迁移到同位置的新卷。成功后的数量和页码一起更新。

**UI-20 · 错误与占位**：缺封面时使用同尺寸占位封面和原始书名；断网或封面 404 不阻止打开其他本地卷。目录为空、未分类、同步失败、文件丢失和仅本地卷各有可区分状态。同步失败保留旧快照，退出账号不展示前账号远程元数据。

**UI-21 · 灰阶与夜间模式**：黑白分类反转、文件夹轮廓、数量徽标和选择框在灰阶及夜间模式均可辨认。位图封面遵循 KOReader 的图像夜间处理方式，不盲目把彩色封面逐像素反转。阴影与标签对比须真机评审。

**UI-22 · 刷新与响应**：加载仅覆盖可见页及有限预取；同一封面不因局部状态更新重解码。进度更新不逐网络块整屏全刷。网络请求不放在 `paintTo`、布局或可见项计算中。下载期间可以浏览、返回、暂停和取消这一既定发布要求保持不变；原型点击通过不能证明非阻塞下载已实现。

## 10. 视觉验收与测试

## 15. 独立离线去彩纹系统

### 15.1 源码研究与技术选择

| 来源及固定版本 | 已观察实现 | 适用于本项目的结论 |
|---|---|---|
| KooComic 当前分支 | 下载器保存原 EPUB，Storage 管理历史路径，下载状态根据实际文件判定；尚无预处理状态 | 保留下载行为；预处理用独立记录与队列，不把处理失败写成下载失败 |
| [Derainbowify](https://github.com/Euphoriyy/derainbowify.koplugin/tree/f2892a219da65bd765d34ae2140a5dd706dfc42b) | LuaJIT FFI 调用原生 FFT，过滤 KOReader 渲染缓存位图；KissFFT 版针对高频对角方向，彩色路径只过滤亮度并保留色度 | 可作为单页原生候选；直接过滤 EPUB 原图与渲染后处理不等效，参数与目标分辨率须实验 |
| [KCC](https://github.com/ciromattia/kcc/tree/55342bd4f90dfdeb065fa8d5a6f4935ffd2da69f) | `imgFileProcessing` 先缩放再调用 `optimizeForDisplay`；`--eraserainbow` 使用 NumPy FFT；Colorsoft 预设 1272×1696 | 参考处理顺序和亮度/色度分离；不把 Python/NumPy 作为 Kindle 生产依赖，不重建整本书的 XHTML 排版 |

第一候选为隔离进程内的原生 FFT，Lua 管理任务与文件状态。最小原型先在开发机验证合成单页的频率抑制、常量保持、色度保持、输入边界和内存使用；开发机原型不是最终 Kindle 功能。确认目标 ABI、图片解码/编码、ZIP 读写与非阻塞进程控制之后，才开放设备端执行入口。

Derainbowify 的 GPL-3.0 源码及 FFT 子库许可须随导入代码保留，记录固定来源、改动与可复现构建。原生包装必须返回明确错误，不能继承 `void` 滤波接口在分配失败后仅打印错误并继续宣称成功的行为。原生代码的静态全局缓冲不支持并发调用，首版仅一个处理 worker。

### 15.2 系统边界与验收要求

**PP-01 · 下载独立**：下载完成即标为已下载并可阅读，默认不触发预处理。下载和预处理不得共用任务状态机；不使用预处理失败或取消覆盖下载记录。未使用该功能的用户保持原有下载与阅读体验。

**PP-02 · 手动管理**：菜单提供“图像优化 / 去彩纹管理”，查看本地有效文件，按未处理/已处理/失败、系列筛选，支持单本及多选手动处理。复用同一封面和选择组件，不创建第二套书架。详情独立展示下载状态与预处理状态，提供处理与查看结果；成功覆盖不可撤销，不提供恢复原版。已优化文件不叠加处理，重新处理需先重新下载原文件；不可用的设备后端须明确禁用执行。

**PP-03 · 独立队列**：新增 `PreprocessQueue`，状态为 `pending / preparing / processing / validating / completed / failed / cancelled`，串行执行；支持去重、取消等待、取消运行、失败重试及重启恢复。重启后运行中的任务转换为中断失败，等待任务恢复但不自动继续；用户手动继续。关闭管理页不丢任务。

**PP-04 · 资源协调**：下载与预处理共享资源协调器，但只共享互斥资源许可，不共享任务状态。已有重下载资源占用时预处理等待，已有解压/FFT 占用时新大文件下载等待或明确提示；失败、取消和异常须释放自己的许可，旧回调不得释放新任务的许可。文件删除、恢复和打开须检查目标是否被处理锁定。

**PP-05 · 结果身份**：处理记录包含 book_id、源路径、可信源指纹、算法版本、处理 profile、页进度、状态、输出指纹和错误。只有源指纹、算法及参数全部一致且实际输出仍存在时，才认为结果可复用。参数变化、重新下载或文件变化不能错误沿用旧完成状态。保留源与输出指纹及无备份策略，不保留原版文件。

**PP-06 · 逐页与离线**：生产执行完全在 Kindle 本地、离线进行；先解析 EPUB manifest，仅逐页解码处理受支持图片，处理后立即释放页缓冲。保留章节文件、资源路径、spine、导航及内部文档结构，未处理资源原样传递。加密/DRM、损坏包、ZIP 路径逃逸、重复成员和解压炸弹拒绝处理；不得一次解压整卷到内存。

**PP-07 · 图像质量**：不采用大幅模糊作为滤波替代；保留灰度、细线、小字与彩色色度。profile 明确目标显示尺寸、缩放/滤波顺序、强度和算法版本；不默认把所有原图降到某分辨率。频率选择依赖最终显示尺度，改变阅读缩放、旋转或裁边后可能再次出现彩纹，必须说明边界。

**PP-08 · 线程与取消**：FFT、解码和压缩不得在 KOReader UI 绘制/调度回调中同步阻塞。`scheduleIn` 仅用于推进与收集独立 worker 状态，不等于异步计算。取消等待任务立即生效；运行任务先通知 worker 安全停止，处理许可直到确认退出才释放；晚到回调不能把已取消任务改回完成。

**PP-09 · 文件安全事务**：处理期间保留原始可读 EPUB，输出写入专用临时文件，完整验证后直接覆盖原路径，不复制或长期保留原版备份。提交前检查源/输出指纹、目标可写、无符号链接逃逸及未打开/未写入。临时文件和最终路径须在同一文件系统以进行原子 rename。处理失败、验证失败、源变化、提交前取消或提交失败都保留原阅读文件；成功提交后原版不可恢复。

**PP-10 · 日志与中断恢复**：持久事务日志记录源/输出指纹、无备份策略及各阶段。启动根据真实文件与指纹核对是否已提交，即使任务完成快照漏存也能恢复状态；不能要求不存在的备份才能确认成功。处理中断保留原文件，原子覆盖后保留已验证输出，不提供恢复原版。历史备份事务保持兼容，旧备份只通过明确删除清理，不静默改写历史任务或清空未知文件。

**PP-11 · 本地状态联动**：处理文件跟随设备级本地管理，退出账号不删源/优化文件。删除时先取消或拒绝活动任务，经确认清理关联优化文件、临时文件和内部备份，不留下无主副本；无法恢复原版的后果在确认中说明。下载同一路径前检查处理资源与文件锁；阅读记录兼容性在同路径与保留内部结构基础上真机验证，不能承诺完全不变。

**PP-12 · 持久化隔离**：预处理设置和任务快照独立于下载记录，可采用单独的 `preprocess` 持久区或文件；保存临时快照后原子替换。设置迁移保留旧下载/账号字段。快照不保存会话、签名 URL 或工作进程对象；读取校验 schema、字段、路径、去重身份与状态。

**PP-13 · 构建与能力探测**：提供固定来源的 native 构建脚本，分别验证 host 与 KOReader Kindle toolchain 的目标 ABI、动态依赖、导出符号和缓冲边界。构建产物不提交为源码，也不误把 amd64 `.so` 发到 Kindle。设备没有可用算法、图片 codec、EPUB writer、资源预算或独立 worker 时保持功能不可用，不用占位后端假装处理完成。

**PP-14 · 真机比较**：同一漫画、同一显示设置比较 A 原版关闭 Derainbowify、B 原版开启 Derainbowify、C 优化版关闭 Derainbowify；记录均值/P95 翻页、首开、峰值内存、处理总时长、额外磁盘和细线/文字/彩纹对照。验收目标 C 的翻页接近 A、画质改善接近 B，具体阈值由实测基线确定；没有 Colorsoft 真机时标记待验证，不编造结果。

**PP-15 · 当前实现证明边界**：纯队列、指纹和文件事务测试通过只证明控制逻辑；host FFT 原型通过只证明选定输入的算法性质。真实 EPUB 重建、目标设备运行、非阻塞 UI、阅读历史恢复及画质改善必须分别提供证据。分阶段提交不等于功能全部完成。

### 15.3 候选状态与文件模型

```text
下载：remote → downloading → downloaded
预处理：pending → preparing → processing → validating → completed
                    └──────────→ failed / cancelled

原始阅读文件 ──只读逐页处理──→ 临时优化包 ──结构/CRC/图片校验──→ 待提交
待提交 ──再次核对源与文件锁──→ 原路径原子替换
事务日志＋实际输出指纹 ──重启核对──→ 恢复完成状态（不恢复原版）
```

预处理去重键是 book_id＋源指纹＋算法版本＋规范化 profile，不使用显示标题或临时 URL。处理资源许可带独立 token，使取消后迟到的回调不能释放另一个任务的资源。

## 16. 最新统一需求与实施约定（v0.4）

### 16.1 决策与边界

用户已明确要求对齐 Bookshelf，并授权更新规格后开始 TDD。比较三条路线：自行重绘不能保证一致；整包导入会引入本地扫描、配置迁移与业务耦合；采用组件级源码复用，保留绘制主体，仅替换数据、字体、主题、缓存及动作接口。采用第三条路线，不再以轮廓相似认定对齐。

- 保留 UI-01..24、REUSE-01..08、PP-01..15 和原始 Next 功能要求，下面的 NV 项建立统一追踪，不缩减范围。
- 移除 Bookshelf 顶部大预览；不复制其阅读进度、评分、微模块、本地扫描或更新器。
- 原书名、默认下载命名和旧路径保留。虚拟系列不自动创建或迁移实体目录。重名冲突拒绝覆盖，不能未经同意追加文件名后缀。
- 完整目录是发行门槛，不发布受限的 28 条版本。探测支持更大 limit 不等于任意账号已完整获取；实现须比较可信 total 和稳定 ID 集合。
- 下载队列、预处理队列是独立状态机，只有资源许可共享；已有预处理队列不能充当批量下载交付证明。
- 合成 EPUB、Linux 渲染与 ARM 静态烟测不代替真实漫画、双插件和 Colorsoft 设备验收。无真机证据时始终标为待验收。

### 16.2 领域与状态

CatalogEntry 是账号内远程文件版本记录；Volume 是经证据确认的卷；Series 是虚拟分组；LocalRecord 是实际文件路径索引。没有可信卷 ID 时不同版本暂不自动合并，不能以标题猜测身份。批量选择保存稳定 entry ID，不保存列表下标。

DownloadJob 使用账号、entry ID 和版本身份去重，只保存请求元数据及状态，不持久化签名 URL/Cookie。PreprocessJob 使用 book ID、源 SHA、算法及 profile 去重。两类任务各有串行运行器和持久快照，资源令牌只能由拥有它的任务释放。

下载暂停只停止启动下一项；当前传输取消须由独立执行后端确认退出。关闭视图不销毁任务，关闭 KOReader 后不承诺继续下载。恢复时运行项标为 interrupted，等待项保留但不自动启动。删除只使用受信本地索引和实际 stat，不调用远端删除，也不递归清空目录。
