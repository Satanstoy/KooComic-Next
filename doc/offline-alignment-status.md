## 验证范围

- 51 组 Lua 5.1 回归，全部插件和测试 Lua 语法检查。
- host动态ABI烟测、6项滤波测试；官方运行时实际生成EPUB/PNG/JPEG处理、20卷
  批次、无原版备份覆盖、中断恢复、真实权限/空间/资源故障。
- 原生目录/本地删除/下载快照/v4迁移、更新包/事务/启动恢复/可移植路径/CRC、
  实际HTTP和下载管理生命周期集成；正式包再跑冷启动安装/回滚/重试。
- UI矩阵、导航、两插件两个顺序的真实ReaderUI链路、组件与五态屏幕对照。
- 固定SDK坏校验拒绝、未跟踪.env/credentials.json/设置备份不入包、编译输入
  摘要、ARM静态QEMU、ZIP/SHA/许可证及两次构建字节一致性。
- `.github/workflows/ci.yml` 固定运行时和Bookshelf源码，自动覆盖以上离机证据。

## 明确未宣称

不把 5000 条生成目录等同网站无限列表；不把受控 HTTP 等同 KOOBONE 私有
服务验证；不把 SDL 逻辑反色或静态 QEMU 等同 Colorsoft 动态加载/显示质量。
SDK glibc动态加载器在本机QEMU的失败已记录，实验包显式标记设备未验证。
未发布正式 Release、未部署 stable 清单，不改变漫画原名，不恢复原版备份。
